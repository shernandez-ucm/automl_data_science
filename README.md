# Time Series Forecasting with AutoGluon for Energy Generation

This project uses the AutoGluon library to perform time series forecasting on energy generation data. The main goal is to predict future energy generation (in MWh) for various power plants based on historical data.

## Project Structure

- `data/`: Contains the raw energy generation data in CSV format, with one file per month for the year 2014.
- `AutogluonModels/`: Stores the trained machine learning models generated by AutoGluon. Each sub-directory represents a different training run.
- `autogluon_generacion.ipynb`: The main Jupyter notebook for this project. It handles data loading, preprocessing, model training, and prediction.
- `autogluon_example.ipynb`: A general-purpose notebook that serves as a cheatsheet for using AutoGluon's time series capabilities.

## Getting Started

### Prerequisites

- Python 3.9+
- Jupyter Notebook or JupyterLab

### Installation

1.  **Clone the repository (if you haven't already):**
    ```bash
    git clone <repository-url>
    cd <repository-directory>
    ```

2.  **Create and activate a virtual environment:**
    ```bash
    python -m venv .venv
    source .venv/bin/activate
    ```

3.  **Install the required libraries:**
    A `requirements.txt` file is not provided, but you can install the necessary packages using pip. The core dependencies are listed in the notebooks.
    ```bash
    pip install autogluon pandas jupyterlab unidecode
    ```

## Usage

The primary workflow is contained within the `autogluon_generacion.ipynb` notebook.

1.  **Start JupyterLab:**
    ```bash
    jupyter lab
    ```

2.  **Open and run `autogluon_generacion.ipynb`:**
    This notebook will guide you through the following steps:
    - **Data Loading:** It loads the data from `data/201401GxSEN.csv`. You can modify the path to process other monthly files.
    - **Preprocessing:** It cleans the data, parses timestamps, and formats categorical features.
    - **Model Training:** It initializes and fits an `AutoGluon TimeSeriesPredictor`. The model is configured to predict the next 168 hours (7 days) of energy generation. The trained models are automatically saved to the `AutogluonModels/` directory.
    - **Prediction:** It uses the best-trained model to generate forecasts.
    - **Evaluation:** It displays a leaderboard showing the performance of all the models that were trained.

## Data

The dataset consists of energy generation reports from the year 2014, separated by month. The data includes the following key columns:
- `Date`, `Hour`: Timestamp information.
- `Generacion_MWh`: The target variable for prediction (energy generation in Megawatt-hours).
- `Codigo Central`: A unique identifier for each power plant.
- `Tecnologia`: The technology used for generation (e.g., Hydro, Solar, Wind).
- `Clasificacion`: Classification of the power plant (e.g., ERNC - Non-conventional renewable energy).
